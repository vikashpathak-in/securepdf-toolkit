PDF workspace

Choose a tool, select your files and download the result. Processing is performed in this browser tab.

Privacy: Your selected document bytes are processed locally by this page. PDF libraries are loaded from public CDNs, so your browser contacts those CDN hosts to download the code. The app does not send your PDF files to a processing server. Avoid using a shared or untrusted device for confidential documents.

Merge PDFs

Combine two or more PDFs in the order selected.

Split PDF

Create a separate PDF for each page range you enter.

Reorder pages

Enter every page number in the exact output order.

Rotate pages

Rotate all pages or only the page numbers you specify.

Extract pages

Save selected pages into a new PDF.

Text watermark

Stamp a text watermark on every page.

Password protection

Apply an AES-256 PDF open password. Keep your password safe.

Uses QPDF WebAssembly in this browser. Encryption support depends on the browser and WASM module loading successfully.

Compress PDF

Rasterise pages into JPEG images to reduce size. This may reduce quality and removes selectable text, links, forms and vector content.

Images to PDF

Convert JPG, PNG and WebP images into a single PDF.

For large documents, keep this tab open until the download completes. Browser memory limits vary. Compression rebuilds each page as an image and is not suitable when you need searchable text or accessible PDF content.
